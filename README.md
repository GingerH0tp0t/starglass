Starglass is a client sided mod for minecraft 1.21.11 that uses the fabric launcher, it adds a sky and allows user to do true astronomy! 

Using your spyglass you can uncover the celestial bodies around you, record data, and eventually, with a little bit of luck, understand the vast galaxy around us.
